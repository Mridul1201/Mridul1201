## 🔬 Currently building

### `Adaptive RAG`

**Adaptive Retrieval-Augmented Generation for Reducing Hallucinations in Large Language Models**

I'm exploring how retrieval strategies can be made more adaptive and context-aware to improve the reliability of LLM responses.

**Currently exploring:**

`Retrieval` → `Chunking` → `Embeddings` → `Reranking` → `Context Selection` → `Generation` → `Evaluation`

> Goal: make AI systems better at knowing **what they know** — and less confident when they don't.
